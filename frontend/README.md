# IntegrovaX - Frontend Client

This is the React-based frontend module for the **IntegrovaX** suite. It contains the dashboards, message tracking views, iFlow builder tools, and all 10 local client-side transformation utilities.

## 🛠️ Scripts

* **`npm start`**: Runs the development web server on `http://localhost:3000`.
* **`npm run build`**: Compiles the React UI into optimized production assets inside the `build/` folder.
* **`npm test`**: Runs Jest unit test suites.
